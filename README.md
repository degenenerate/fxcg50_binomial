# fx-CG50 Binomial
- Calculates binomial expansion for rational coefficients of: (ax+b)^p and a(1+bx)^p
- To build, clone this repo into the projects directory of the PrizmSDK: https://github.com/Jonimoose/libfxcg/releases/tag/v0.6
- Running `make` will create a .g3a file (binomial.g3a) which you can just copy into your calculator by USB
